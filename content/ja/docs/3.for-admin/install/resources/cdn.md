# CDNの設定
Misskeyサーバーを公開するときは、[Cloudflare](https://www.cloudflare.com/)などのCDNを使用することを強くおすすめします。

CDNを使用することで、以下のようなメリットがあります。
- 静的なコンテンツをキャッシュしてもらうことができ、サーバーの負荷が低減する
- サーバーのIPアドレスが露出しにくくなることで、DoS攻撃などを緩和できる

## キャッシュ
Misskey Webは、完全に静的であり、動作にサーバーを必要としません。したがってMisskey Web全体をCDNでキャッシュすることができます。
Misskey APIはキャッシュすることはできません。

CDNで以下の設定を行なってください。
- `/api/*`以外のリクエストをすべてキャッシュする

:::tip

Misskeyをアップデートした際にキャッシュのクリアは不要です。

:::

さらに、CDNのデフォルト設定では、コンテンツのキャッシュ期間が1時間など、短い期間になっている場合があります。
アップロードされたカスタム絵文字のファイルなど、コンテンツの内容が変化することのないURLが効率的にキャッシュされるようにするため、キャッシュ期間をより伸ばすか、MisskeyサーバーがHTTPレスポンスのヘッダーとして送信するキャッシュ期間指定をCDNが順守するような設定にすることを推奨します。

## CDNの追加機能について

CDNによっては、サーバーが送信するWebページ内容を最適化する機能(JavaScriptをminifyする等)が提供されている場合があります。
Misskeyは、既に最適化されており、それらの機能は益がないばかりか、Misskeyが利用するWeb仕様と互換性がないために不具合を発生させることがあります。
そのため、CDNの最適化内容にもよりますが、基本的にこれらの機能を使用することは推奨しません。
