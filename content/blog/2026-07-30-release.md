# NEW RELEASE: v2026.7.0

Misskey Projectは2026年7月30日、Misskey v2026.7.0 をリリースしました！

今回のリリースでは、多くの新機能・改善・バグ修正を行う大型リリースとなっています。

## 画像ビューワーの刷新

ノートの添付ファイルの閲覧時などで使用される画像ビューワーを刷新しました！

![画像ビューワーのスクリーンショット](/img/blog/2026-07-30-release/lightbox-1.png)

これまでMisskeyでは、画像ビューワーとして [PhotoSwipe](https://photoswipe.com/) を使用していましたが、今回のリリースでMisskey独自の画像ビューワーに置き換えました。これにより、以下のような改善が行われています。

### 動画プレイヤーの統合

画像ビューワーに動画プレイヤーを統合し、動画の拡大にも対応しました。これにより、スマートフォンなど画面幅が狭いときに動画の再生が難しいという問題が解消し、より快適にメディアを楽しむことができます。

![動画プレイヤーのスクリーンショット](/img/blog/2026-07-30-release/lightbox-2.png)
*(c) copyright 2008, Blender Foundation / https://peach.blender.org/*

### 画像ビューワーの他の機能への展開

ファイルアップローダーや、ノートの投稿フォームでもこの画像ビューワーが使用できるようになりました。ファイルアップロード前や、ノートの投稿前に、投稿するメディアを拡大して確かめることができます。

### 各種 UI の改善

Misskey のコア UI と統合されたことにより、Misskey ならではのニーズに応えられる画像ビューワーとなりました。

例えば、センシティブな画像とそうでない画像が混じったノートを閲覧する際に、ビューワー上で開いたセンシティブな画像をぼかし表示するようになりました。これにより、意図せずセンシティブな画像を閲覧してしまうことを防ぐことができます。

![センシティブ画像のぼかし表示のスクリーンショット](/img/blog/2026-07-30-release/lightbox-3.png)

また、ファイルの詳細情報や、ファイルに対して取れるアクションをメニューとして表示するようになり、統合されたエクスペリエンスを提供できるようになりました。

![画像ビューワーのメニュー表示のスクリーンショット](/img/blog/2026-07-30-release/lightbox-4.png)

他にも、従来の画像ビューワーでは実現が難しかった機能に対応したり、パフォーマンスを向上したりといった様々な細かな改善も行っています。ぜひお試しいただき、ご意見をお聞かせください。

## センシティブメディアの判定を外部化

アップロードされるメディアのセンシティブ自動判定を、外部サービス [sensitive-detector](https://github.com/misskey-dev/sensitive-detector) を使用する形に変更しました。これにより、判定精度の向上や、判定処理の負荷軽減が期待できます。

現在センシティブ自動判定を利用しているサーバーでは別途対応が必要です。詳しくは[リリースノート](/docs/releases/)をご覧ください。

## ログ基盤の刷新

Misskey バックエンドのログ基盤を刷新し、様々な改善を行いました。

- ログをJSON形式で出力可能になりました。
- ログの出力レベルを、ドメインごとに変更することができるようになりました。
- 将来的に、ログを OpenTelemetry のトレースコンテキストに紐付けて出力可能になる予定です。

## 動作要件の変更

今回のリリースは、上記のセンシティブ自動判定の外部化と合わせて、以下の動作要件変更を実施しています。サーバー管理者の方はアップデート前にご確認ください。

- Node.js v24 および v26 をサポートしました。近日中のリリースで v22 のサポートを終了する予定ですので、v22 をご利用の方はアップグレードをご検討ください。
- Node.js のセキュリティアップデートに伴い、最低動作バージョンを 22.22.2 / 24.17.0 / 26.4.0 に引き上げています。
- 画像処理ライブラリの都合上、SSE4.2 命令セットをサポートしていない x86_64 CPU では Misskey が正常に動作しません。仮想マシンに Misskey をデプロイしている場合や、古いハードウェアをお使いの場合は、アップデート前にお使いの環境をご確認ください。なお、ARM64 など x86_64 ではない環境においてはこの変更による影響はありません。

## その他の主な変更点

さらに以下のような改善・機能追加を行っています。

- ユーザーの二要素認証を管理者が解除することができるようになりました。
- 管理者が設定した条件に一致したURLプレビューのサムネイルを隠すことができるようになりました。
- URLプレビューの結果をバックエンドで短時間キャッシュするようになりました。
- Sentry のトレースを機能ごとに無効化できるようになりました。
- フロントエンドにおいて多数のパフォーマンス改善を行いました。
- **セキュリティに関する修正を行いました。**

今回のリリースには他にも多くのバグ修正・機能改善が含まれています。詳しくは[リリースノート](/docs/releases/)をご覧ください。
